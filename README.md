# HIKER - Django E-commerce Website

**HIKER** is an e-commerce website built with Django that specializes in selling camping gadgets and accessories like tents, compasses, harnesses, ropes, sleeping bags, and more. This project features both user and admin functionalities, including advanced sales analytics, product management, and discount coupon management.

## Features

### User Features
- **Product Browsing**: Users can browse a wide range of camping gadgets.
- **Product Search & Filters**: Search and filter products by categories or keywords.
- **Product Variants**: View and select various product variants (e.g., color, size).
- **Shopping Cart**: Add products to a cart and proceed to checkout.
- **Order History**: Users can view their past orders.
- **Coupons**: Apply discount coupons during checkout.
- **Secure Payment**: Payment integration through Razorpay or other secure payment gateways.

### Admin Features
- **User Management**: View, edit, and manage user accounts.
- **Product Management**: Add, update, and delete products, categories, and product variants.
- **Coupon Management**: Create, update, and delete discount coupons for users.
- **Sales Analytics**: Weekly, monthly, and yearly sales data visualized through interactive charts.
- **Comprehensive Sales Reports**: Generate sales reports for different time periods, available in downloadable formats.
